Drop your PNG/JPG captures here with these exact names (referenced by the main
`README.md`):

| File | View to capture |
|---|---|
| `dashboard.png` | Home dashboard (recently clicked / added / per collection) |
| `links.png` | The links list (`/links`) with the compact cards |
| `collection.png` | A collection detail page (`/collections/{id}`) with sub-folders + links |
| `tags.png` | The tags page (`/tags`) — the tag cloud |

| `new-link.png` | The "New link" form |

Tip: capture at a normal window width (~1200px) for the desktop grid, and add a
mobile capture too if you like. Keep them reasonably light (resize/compress).
